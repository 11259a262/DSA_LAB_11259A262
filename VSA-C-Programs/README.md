## Requirements

- Windows 10 / 11
- GCC / MinGW Compiler
- Standard C runtime (`<stdio.h>`, `<stdlib.h>`, `<string.h>`, `<ctype.h>`)

---

## How to Compile

To compile any program manually using GCC:

```bash
cd Program_01
gcc Program_01.c -o Program_01.exe
```

---

## How to Run

To run the compiled binary:

```bash
Program_01.exe
```
